# 03. UI/UX Specification

## Aesthetic Direction: Premium Minimal
The interface emphasizes calm focus, typography rhythm, and clarity:
- **Canvas / Background**: Warm ivory (`#FAF8F5`) / Twilight Dark (`#151413`).
- **Surfaces / Cards**: Warm soft gray-beige (`#F3EFE9`) / Card Dark (`#201E1B`).
- **Primary Accent**: Restrained Burnt Orange (`#D95D29` / `#E06D3B`).
- **Text**: Deep Graphite (`#282420`) / Off-White (`#EAE7E2`).
- **Status Accents**:
  - Success / On Track: Accessible Green (`#1E7F4D`)
  - Warning / At Risk: Warm Amber (`#B45309`)
  - Danger / Below Target: Crimson Red (`#C53030`)

## Typography Hierarchy
- Modern Sans-Serif: Plus Jakarta Sans.
- Display Header: 22–24px, Bold (700).
- Section Titles: 16–18px, SemiBold (600).
- Body Text: 14–15px, Regular/Medium (400/500).
- Stat Figures: 24–32px, Bold (700) with Tabular figures.

## Spacing & Touch Targets
- Minimum touch target: 44px × 44px for accessibility.
- Card padding: 16px to 20px.
- Border radius: 12px to 16px (mathematically balanced).
