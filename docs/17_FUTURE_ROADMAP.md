# 17 — Future Roadmap
**Student Attendance Tracker** • *Potential Enhancements*

---

## 1. Candidate Features
1. **NFC Tag Quick Check-in**: Tap a personal desk/notebook NFC sticker to trigger attendance logging.
2. **Timetable Calendar Sync**: Optional export of class schedule to local Android Calendar (without cloud sync).
3. **Wear OS Companion App**: Quick glance and one-tap attendance marking from smartwatches.
4. **Enhanced Timetable Conflict Detection**: Visual alert when two recurring classes overlap in the weekly schedule.

---

## 2. Explicitly Excluded (Out of Scope)
- College portal scraping / automated login hacks (unreliable, breaches university ToS).
- Cloud accounts / Firebase sync (violates offline-first student ownership principle).
- GPS-as-proof verification (unethical and inaccurate for lecture attendance).
